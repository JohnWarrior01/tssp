# Отложенная передача в ТССП

Посредник принимает зашифрованные файлы и текст до 32 КБ. Отправитель может
отключиться после загрузки. Получатель вводит скопированный код T1-… и адрес
того же посредника. Код чувствителен к регистру. Передавайте его получателю
по защищённому каналу.

## Развёртывание

1. Создайте отдельный приватный репозиторий GitHub и инициализируйте его
   первым коммитом, например README.
2. Выдайте fine-grained токен только для этого репозитория с правами
   Contents: Read and write. Установите переменные окружения на сервере:
   TSSP_GITHUB_REPO (OWNER/REPO), TSSP_GITHUB_TOKEN и TSSP_UPLOAD_TOKEN.
   Последний — отдельный пароль отправителя. Используйте случайную строку
   длиной от 24 символов. Получателю этот пароль не нужен.
3. Запустите python broker.py на сервере с Python 3.11+. Процесс слушает
   127.0.0.1:8765. Настройте HTTPS reverse proxy на этот порт. Передавайте
   заголовок Authorization, ограничьте размер тела 64 КиБ, настройте
   ограничения частоты запросов и исключите пути /v1/* из журналов доступа.
   Не открывайте порт 8765 напрямую в Интернет.
4. В ТССП включите «Отложенная отправка», выберите файл или текст,
   введите HTTPS-адрес посредника и пароль загрузки. Приложение скопирует
   код. Получатель вставляет код на обычном экране получения и вводит
   адрес посредника.

Клиенты шифруют содержимое и имя файла AES-256-GCM до отправки. Код содержит
случайный 256-битный ключ. Посредник получает идентификатор, вычисленный
из ключа, и зашифрованный пакет. Токен GitHub хранится только на посреднике.

Посредник выдаёт пакет максимум один раз, в течение 24 часов. Он удаляет
файл из текущей ветки перед ответом. Если соединение оборвётся после удаления,
понадобится новая отправка. При обращении к просроченному коду файл также
удаляется. Истёкшие записи без запросов остаются в ветке, а Git сохраняет
зашифрованные данные в истории коммитов. Учитывайте это при выборе срока
хранения репозитория. Сервер рассчитан на один процесс и небольшую нагрузку.

GitHub Contents API — https://docs.github.com/en/rest/repos/contents
